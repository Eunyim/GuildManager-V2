# 길드 매니저 작업 일지 (2026-10-17 ~ 10-18)

앞 일지(`작업일지_2026-10-15_16.md`)의 25~34장을 한 세션 단위로 다시 정리한 문서입니다. 수치는 모두 자동 플레이 봇(`Tools > TEMP 4주 플레이`)으로 잰 값이고, 화면에 어떻게 보이는지는 확인하지 못했습니다(6장 참고).

## 2. 한 일

### 2.1 보스 HP 1.5배 (10/17)
- 사용자 결정. `BattleManager.bossHpMultiplier = 1.5` (MakeBoss에서 `BattleUnit.MultiplyHpScaling`). 6종 공통, 분열체·소환 졸개는 영향 없음.
- 6명 파티 견제는 지금은 안 하기로 함.

### 2.2 재료 수급 종족 편향 50% → 80% (10/17, 이후 2.7로 대체)
- 사용자 지시. `QuestTypeRules.gatherRaceBias = 0.8`. 측정은 3.1.

### 2.3 킹 슬라임 개편 (10/17)
1. **스킬 삭제, 점프로만 이동**: 점프 내려찍기 삭제, maxMp 0(MP 바 숨김). 대상 쪽으로 깡충 뛰어 이동. 수치(제가 정함): `hopDistance 1.2 / hopDuration 0.6초 / hopHeight 1.0 / hopInterval 1.4초`. 공용: `BattleUnit.StopAndAttack`은 maxMp 0이면 스킬을 안 씀, `HPBar`는 maxMp 0이면 MP 바 숨김.
2. **제자리에서도 계속 점프**: 쉬는 시간이 끝날 때마다 항상 뜀. 대상이 멀면 그쪽으로 최대 1.2칸, 사거리 안이거나 착지점이 바닥 밖이면 제자리.
3. **착지 범위 피해**: 단일 공격 삭제. 모든 착지가 공격, ~1m 100% / 1~3m 80% / 3~5m 50%. `kingAttackPower` 30 → 40(제가 정함). `EnemySlime.landingSplash`(`SplashFalloffSettings`), 계산은 `Core/SplashFalloff.cs`.
4. **쉬는 시간 1.4초 → 2.0초**: 사용자 지시. 코드 기본값 + `Enemy_KingSlime`·`Enemy_Slime` 프리팹.

### 2.4 도적 은신 중 피해 면역 (10/18)
- 사용자 지시. 은신 중 일반 공격·범위 공격·출혈·화상 모두 무효(지속 시간은 흐름), "IMMUNE" 글자.
- 공용 `BattleUnit.IsDamageImmune`(virtual, TakeDamage·지속 피해에서 확인), `Ally_Rogue`는 은신 중 true, `BattleManager.ShowImmuneText`.

### 2.5 방 적 뽑기 규칙 변경 (10/18)
- 사용자 결정. 뽑는 횟수 D 1~2 / C 2~3 / B 3~4 / A 4~5 / S 5~6 (이전 B 2~3, A 3~4, S 3~5).
- C랭크 이상은 절반(올림)은 의뢰 랭크, 나머지는 한 단계 아래 랭크로 뽑음. 아래 랭크 뽑기는 **무리 크기만** 한 단계 아래(능력치 배율은 의뢰 랭크 그대로). 웨이브 방은 2차례 합친 횟수에 같은 규칙.
- 코드: `Core/RoomSpawnRules.cs`(`RoomSpawnSettings`), `QuestGenerator.roomSpawn`(인스펙터에서 조정, 예전 하드코딩 GetEnemyCount 대체).

### 2.6 방어력 스탯 (10/18)
- 사용자 결정: 비율 감소, 모험가만(적은 0), HP·공격력처럼 성장.
- 수치(제가 정함, `GameManager.defense` = `DefenseSettings`): Lv.1 D랭크 기준 전사 15 / 사제 8 / 궁수·마법사·도적 5, 레벨당 전사 +2 / 나머지 +1, 랭크 배율은 HP·공격력과 같음, ±10% 무작위. 예: A랭크 Lv5 전사 약 52(피해 -34%), 마법사·도적 약 18~21(-15~17%).
- 전사 받는 피해 -20%와 곱으로 겹침, 출혈·화상은 무시. 동시 파견 전투력은 HP × (1 + 방어력/100). 예전 저장은 불러올 때 다시 계산.
- 표시: 레벨업 로그(DEF+), 접수처 카드, 모험가 정보 창, 전투 중 마우스 오버.

### 2.7 재료 수급 의뢰 개편 (10/18)
- 사용자 결정: 몰림 대신 그 재료 드랍률을 올림.
  1. 몰림 0 (`gatherRaceBias` 0.8 → 0)
  2. 필요 개수 = 던전 재료 몬스터 원래 드랍률 합 ÷ 100 (반올림, 최소 1). 미믹 후보 제외, 보스·웨이브 방 포함. 합이 100% 미만이면 던전 재생성(최대 20번), 그래도 모자라면 전투 방에 재료 종족 보충
  3. 의뢰 중 그 재료 드랍률 × 1.5 (최대 100%)
  4. 다 모으면 그 재료는 드랍 0
  5. 막판 보장: 남은 재료 몬스터 수 ≤ 못 모은 개수가 되면 100% 드랍
- 모든 적의 드랍을 `DropItem.Roll(table, 이름, this)` 하나로 통일(개별 CheckDrop 제거).
- 코드: `Core/GatherRules.cs`, `Data/DropTableLookup.cs`, `QuestGenerator.BuildGatherStages`, `QuestData.gatherDropRateMultiplier/gatherGuaranteeAtEnd`, `BattleManager.InitGatherTracking/GetDropRate/OnDropSourceDied`.

### 2.8 잠재력 → 레벨당 성장량, 소수 이월 (10/18)
- 확인해 보니 같은 직업 안 능력치 차이가 ±10%뿐이고 잠재력은 능력치에 영향이 없었음.
- 사용자 결정: 잠재력 1/2/3/4/5 → 레벨당 성장 ×1.0/1.1/1.2/1.3/1.4 (배율은 제가 정함, `GameManager.potentialSettings`). 생성기는 잠재력을 먼저 정함.
- 반올림으로 사라지던 소수를 다음 레벨업으로 이월(`Adventurer.hpGrowthCarry/atkGrowthCarry/defGrowthCarry`, 세이브 포함). 예: C랭크 사제 공격력 2.4 × 9레벨 → 이전 18, 이월 22(정확 21.6).
- HP·공격력 성장 공식을 `Core/StatGrowthRules.cs` 한 곳으로 모음(GameManager와 생성기에 두 벌 있던 것 정리).

### 2.9 버그 수정
- **구출 의뢰가 안 끝남**: 보스를 먼저 잡고 다른 방에서 구출하면 클리어 판정이 없었음(사용자 발견) → `BattleManager.FinishIfRescuedAfterBoss()`. 재실행에서 정상 종료 확인.
- **맵 밖 이탈**(사용자 제보: 사제·궁수가 도망치다 맵 밖으로):
  - 원인: "바닥 밖으로 안 감" 판정이 바닥 위에 있을 때만 걸림, 스폰·모닥불 자리가 바닥 밖일 수 있음, 넉백에 바닥 판정 없음, **물리 충돌 밀림은 바닥 판정을 거치지 않음**.
  - 수정: `MapGenerator.NearestFloor`, `MoveStep`이 바닥 밖 이동 거부, `BattleUnit.ReturnToFloor()`, 넉백 바닥 판정, `BattleUnit.KeepOnFloor()`(조금 밀려나면 마지막 바닥 위치로). 바닥 밖 비율 3.2% → 0.11%.
- **좁은 맵·적 겹침**(사용자 제보: 늑대가 마법사 스킬 한 방에 전멸):
  - 원인: 방이 화면보다 작았고, 적 스폰 자리가 9개뿐이라 10번째 적부터 같은 자리에 겹침.
  - 수정: `MapGenerator.isoRoomSize = 22`(18이면 예전 크기), 적 대형을 세로 열 방식으로(`enemyRowsPerColumn 4`, `enemyRowSpacing 1.5`, `enemyColumnSpacing 1.6`, 자리 수 제한 없음).

### 2.10 로비 치비 외형 (10/18)
- 사용자 요청. 모든 직업이 같은 동그라미였던 `Prefab_LobbyChibi`가 직업별 전투 프리팹과 같은 몸통 + 무기로 나옴.
- `Runtime/LobbyChibiLook.cs`(SpriteRenderer → UI Image), `LobbyManager.chibiWarriorPrefab` 등 5칸, `chibiHeight 100`. `Tools > 로비 치비 외형 연결`(`Editor/LobbyChibiLinker.cs`)로 로비 씬에 저장.
- 플레이 모드에서 5직업 모두 그림이 맞게 들어간 것 확인.

### 2.11 봇 확장
- 옵션: `bossOnly`(보스방 외 전부 휴식 방), `slimeOnly`, `kingHopInterval`, 랭크 강제 시 지정 지역에서 생성.
- 집계: 의뢰마다 전투 방 적 수, 바닥 밖 유닛 비율.
- 던전 한도 300 → 900초, 교착 판정 240 → 600초(맵이 커져 던전이 길어짐).

## 4. 발견된 문제점과 해결 조언

### 4.1 오크 부락 A의뢰가 A랭크 파티에게 거의 불가능
- **현상**: A랭크 4명·6명 모두 0승(34장). 첫 방에서 후열 2명이 쓰러지는 패턴.

- **조언**: (1) 아래 랭크로 뽑힌 적은 능력치 배율도 한 단계 아래로, (2) 뽑는 횟수를 이전(A 3~4)으로 되돌리기, (3) 무리 종족은 1번 뽑을 때 횟수 2번으로 치기 중 하나. 1번이 규칙 취지(절반은 약한 적)에 가장 맞습니다.

==============================================================
 길드 매니저 - 특성 목록 (2026-10-18 기준)
==============================================================

모험가에게 붙는 특성은 두 종류가 있다.

  1) 성격   : 모험가마다 1개. 고용 시 6종 중 무작위.
              ※ 현재 설명 문구만 있고 전투 효과는 구현되지 않음.
  2) 특성   : 여러 개 가질 수 있음. 실제로 전투에 적용됨.
              긍정 특성 / 트라우마 / 우울함으로 나뉨.

  · 여러 특성의 배율은 곱해진다. (예: 1.2 × 0.7 = 0.84 → 공격력 -16%)
  · 조건은 전투 중 매 프레임 다시 확인한다.


--------------------------------------------------------------
 1. 성격 (6종) - 효과 미구현
--------------------------------------------------------------

  이름      분류    설명
  ------    ------  ---------------------------------------------
  평범함    -       특별한 장점도, 단점도 없다.
  겁쟁이    부정    체력 30% 이하에서 도망갈 확률이 높다.
                    아군의 뒤에 숨기를 좋아한다.
  다혈질    부정    적에게 달려들기를 선호한다. 어그로를 무시한다.
  공명심    양면    막타를 칠 수 있는 적을 우선 공격한다.
  신중함    양면    가만히 서서 지켜보기를 좋아한다.
                    가만히 있을 때 방어력이 올라간다.
  게으름    부정    가끔 공격하지 않고 멍하니 서 있다.


--------------------------------------------------------------
 2. 긍정 특성 (5종)
--------------------------------------------------------------

  얻는 법
    · 고용 시 시작 특성 : B랭크 30% / A랭크 60% / S랭크 100% 확률로 1개
                          (D·C랭크는 없음)
    · 레벨업            : 3레벨마다 50% 확률로 1개 (이미 가진 것은 제외)

  이름          조건                              효과
  ------------  --------------------------------  ----------------------
  용사의 기운   항상                              공격력 +20%
  전투 본능     항상                              공격력 +15%
  강인한 의지   항상                              이동속도 +15%
  외톨이        반경 3 안에 아군이 없을 때        공격력 +30%
  외향적        생존 아군이 출발 인원의 50% 이상  공격력 +20%
                생존 아군이 출발 인원의 50% 미만  공격력 -20%

  ※ 외향적 예시
      4명 출발 : 2명 이상 생존 → +20% / 1명만 남음 → -20%
      6명 출발 : 3명 이상 생존 → +20% / 2명 이하   → -20%


--------------------------------------------------------------
 3. 부정 특성
--------------------------------------------------------------

 [트라우마 3종]
  얻는 법 : 체력 30% 이하(중상)로 던전에서 돌아오면 50% 확률로
            아래 3종 중 1개 (이미 가진 것은 제외)

  이름      조건            효과                              치유
  ------    --------------  --------------------------------  ----------
  겁쟁이    체력 30% 이하   적을 노리지 않고, 최대 체력이     신전 가능
                            가장 높은 아군을 따라간다
  공포증    항상            공격력 -30%                       신전 가능
  외팔이    항상            공격력 -40% (신체적 특성)         신전 불가

 [우울함]
  얻는 법 : 케미 Lv.3 이상이던 파티원이 사망했을 때
  조건    : 항상
  효과    : 공격력 -15%
  사라짐  : 정해진 기간이 지나거나, 새 동료와 케미가 기준 레벨에 도달하면
  ※ 이미 우울한 상태에서 다시 걸리면 기간이 다시 채워진다.

 [외향적] (긍정 특성 풀에 있지만, 아군이 절반 미만이면 공격력 -20%)


--------------------------------------------------------------
 4. 겹쳤을 때 예시 (곱연산)
--------------------------------------------------------------

  외향적(+20%) + 공포증(-30%)         1.2  × 0.7  = 0.84  → -16%
  용사의 기운(+20%) + 전투 본능(+15%) 1.2  × 1.15 = 1.38  → +38%
  외팔이(-40%) + 우울함(-15%)         0.6  × 0.85 = 0.51  → -49%
  외팔이 + 공포증 + 우울함            0.6 × 0.7 × 0.85 = 0.357 → -64%


성격 - 성격은 보통 모험가 AI의 움직임이나 케미 등의 비전투요인에 직접적으로 관여하며 전투에 간접적으로 관여한다.(= 스탯에 직접적으로 관여하지 않는다.) 랭크가 올라도, 모험가 당 한 개씩만 가질 수 있다. 성격에는 부정도, 긍정도 없다. 성격은 그저 모험가가 타고난 기질이다. 성격은 모험가 상세 정보 직업란에 수식어로 붙을 수 있다. (Ex. 평범한 궁수, 용감한 마법사 등등)

--------------------------------------------------------------
 1. 성격
--------------------------------------------------------------

평범한 - 아무런 효과 없음.
겁쟁이 - 중상을  입거나, 아군이 절반 이상 사망하면 힐을 받을 때 까지 아군의 뒤로 숨으려고 한다.
다혈질 - 적을 향해 돌진하려 한다. 10% 확률로 어그로를 무시하고 돌진한다.
덜렁거리는 - 획득하는 골드 -10% 
신중한 - 
게으른 - 전투 중에 10%확률로 행동을 1.5초 동안 멈춘다.
나르시시스트 -
운 좋은 - 희귀 드랍 아이템 얻을 확률 10% 증가  
이타적인 - 아군에게 붙은 적을 먼저 처리하려고 한다.
외향적인 - 케미 적응 속도 + 10%, 관계에서 받는 스트레스 + 10%
겸손한
태평한 - 정신적 트라우마 얻을 확률 30% 감소.
내향적인 - 케미 적응 속도 - 10%, 관계에서 받는 스트레스 - 10%

2. 특성 - 전투에 직접적으로 관여하는 수치
  용사의 기운  스탯 +20% - (이는 A급에서 5% 확률, S급에서 10%확률로 출현한다. 만약에 혼자 끝까지 던전을 클리어 할 경우 30%확률로 습득한다.)
  광전사 - 잃은 체력에 비례하여 공격력 상승
  빠른 발  이동속도 +15%, 회피율 + 10%
  외로운 늑대 - 파티가 절반 이상 일 때 스탯 - 10%, 절반 이하로 떨어졌을 때 + 20%
  단단한 피부 - 방어 +10%, 출혈 저항 +5%
  육감 - 다음 방을 미리 볼 수 있다. (모든 랭크에서 10% 확률로 등장)
  괴수 사냥꾼 - 늑대, 슬라임 상대로 추가 데미지 10%
  인간 사냥꾼 - 도적단 상대로 추가 데미지 10%
  언데드 사냥꾼 - 스켈레톤 상대로 추가 데미지 10%
  강인함 - 받는 스턴 시간 10% 감소
  그린스킨 사냥꾼 - 오크, 고블린 상대로 추가 데미지 10%
  드래곤슬레이어 - 드래곤 상대로 추가 데미지 20%(이미 드래곤을 사냥한 전적이 있는 모험가, 즉 막타를 친 모험가) = 이스터에그
  
3. 트라우마와 결함 - 중상으로 돌아오면 30% 확률로 트라우마나 결함 중에서 획득, 빈사로 돌아오면 50% 확률로 획득, 낙오자는 80%확률로 획득. 이미 가진 것은 제외. 트라우마는 신전에서, 결함은 치유소에서 치료 가능.

3-1  트라우마
괴수 공포증 - 늑대, 슬라임 상대로 가하는 데미지 - 10%
도적 공포증 - 도적에게 가하는 데미지 - 10%
언데드 공포증 - 스켈레톤에게 가하는 데미지 - 10%
그린스킨 공포증 - 고블린, 오우거에게 가하는 데미지 -10%
드래곤 공포증 - 드래곤에게 가하는 데미지 -10%
우울함(기존의 그 우울함 맞음)

3-2 결함
외팔이 - 가하는 데미지 -30%
절름발이 - 이동속도 -30%
외눈박이 - 회피율 -30%
약골 - 받는 피해 +30%

기본공격 치명타 시스템 추가, 회피율 추가. 회피율과 치명타는 기본 10%, 레벨업으로 증가하지 않는다. 도적만 회피율 30%, 치명타 30%.
몬스터 스탯 추가
관계 시스템 추가 - 무드 시스템 추가. 
폴리싱 작업 - 던전 선택시 던전 이미지 구현 (잠긴 곳은 흑백 및 자물쇠와 X 표시)

## 2. 한 일

- 한 줄 텍스트 안의 이름마다 따로 판정합니다(TMP `<link>`).
  - 이름에 밑줄이 그어지고, 말풍선은 마우스 오른쪽 아래에 뜹니다. 화면 밖으로 나가지 않습니다.
  - 다른 팝업에 가려져 있으면 뜨지 않습니다.
- 툴팁 아래 보충 설명: 치료 장소, 우울함은 남은 주 수.
- 분류별 색: 트라우마 빨강, 결함 주황, 좋은 관계 분홍, 라이벌·불화 보라.

### 2.2 성격 13종 (사용자 기획안)
| 성격 | 효과 |
|---|---|
| 평범한 | 없음 |
| 겁쟁이 | 중상(30% 이하)이거나 아군이 절반 이상 쓰러지면 힐을 받을 때까지 아군 뒤로 숨음 (모닥불 휴식도 회복으로 봄) |
| 다혈질 | 대상을 고를 때 10%로 어그로를 무시하고 가장 가까운 적에게 돌진, 그 적을 쓰러뜨릴 때까지 고정 |
| 덜렁거리는 | 파티가 얻는 골드 −10% (한 명마다 곱함) |
| 신중한 | 보물상자가 미믹이면 50%로 알아챔 → 미믹이 2초 기절한 채로 나옴 |
| 게으른 | 공격하려 할 때 10%로 1.5초 멈춤 |
| 나르시시스트 | 막타를 칠 수 있는 적(체력이 내 공격 2번 이하)을 먼저 노림, 사기 변동 ×1.5 |
| 운 좋은 | 희귀 드랍(기본 확률 10% 이하) 확률 ×1.1 |
| 이타적인 | 아군을 노리는 적을 먼저 공격 |
| 외향적인 / 내향적인 | 케미 적응 속도 ±10%, 관계 스트레스(우울함 확률) ±10% |
| 겸손한 | 월급 −10%, 같은 파티원의 우울함 확률 −10% |
| 태평한 | 정신적 트라우마(공포증·우울함) 확률 −30% |

- 신중한·나르시시스트·겸손한은 기획안에 효과가 비어 있었습니다. 제가 조언한 안을 사용자가 채택했습니다.
- enum 순서는 저장 호환을 위해 기존 6종 자리를 유지했습니다. 3번(예전 공명심) 자리가 덜렁거리는입니다.

### 2.3 특성 (사용자 기획안)
- **일반 9종:** 광전사(잃은 체력 비례, 최대 +30%, 사용자 결정), 빠른 발, 외로운 늑대, 단단한 피부, 괴수·인간·언데드·그린스킨 사냥꾼, 강인함.
  - 기존처럼 고용 시 시작 특성(B 30% / A 60% / S 100%)과 레벨업(3레벨마다 50%)으로 얻습니다.
- **특별 3종:**
  - 용사의 기운: 고용 시 A 5% / S 10%, 혼자 살아남아 던전을 돌파하면 30%
  - 육감: 고용 시 10%. 지금 방과 이어진 방의 종류가 지도에 보임
  - 드래곤슬레이어: 진짜 드래곤에게 마지막 일격을 넣으면 얻음 (베이비·해츨링 제외)
- '스탯' = 공격력·방어력·이동속도 (최대 체력 제외). 사용자 확인.
- 외로운 늑대: 살아 있는 파티원이 50% 이상이면 −10%, 50% 미만이면 +20%. 사용자 확인.
- 예전 특성(전투 본능, 강인한 의지, 외톨이, 외향적)은 지웠습니다.

### 2.4 트라우마·결함 (사용자 기획안)
- 중상 30% / 빈사(10% 이하) 50% / 낙오 80%로 9종 중 1개를 얻습니다 (이미 가진 것은 제외). 동시 파견도 같습니다.
- 트라우마: 괴수·도적·언데드·그린스킨·드래곤 공포증(그 계열에게 주는 피해 −10%), 우울함(기존 그대로, 동료가 죽었을 때만).
- 결함: 외팔이(주는 피해 −30%), 절름발이(이동속도 −30%), 외눈박이(회피율 −30%p), 약골(받는 피해 +30%, 출혈·화상 포함).
- 적 계열 판별은 프리팹 이름으로 합니다(`EnemyFamilyRules`). 미믹은 계열이 없습니다.

### 2.5 전투 규칙 확장
- `BattleUnit.TakeDamageFrom(attacker, damage, crit)`
  - 아군의 기본 공격·스킬·화살·파이어볼이 모두 이걸 거칩니다.
  - 대상 계열별 피해 배율과 막타 기록(드래곤슬레이어)을 처리합니다.
- 새 효과: 회피(MISS 표시), 받는 피해 배율, 받는 출혈 피해 배율, 받는 스턴 시간 배율, 잃은 체력 비례 공격력.
- `TraitData`에 분류(`category`)와 추가 효과(`extraEffects`)를 넣어, 한 특성이 효과를 여러 개 가질 수 있게 했습니다.
- 화면 글자는 폰트 때문에 영문·기호만 씁니다: MISS(회피), Zzz(멍때리기), !(돌진·미믹 간파).
- 모험가는 특성이 없어도 매 프레임 기본값으로 되돌린 뒤 배율을 곱합니다 (라이벌 배율이 쌓이지 않게).

### 2.6 치유소 (사용자 지시)
- 길드 밖 화면에 [치유소] 건물을 추가했습니다. 건물이 4채가 되어 간격 600 → 460, 폭 440 → 400으로 줄였습니다.
- 창에서 결함을 가진 모험가 목록을 보고 결함마다 [치료]합니다. 의뢰를 나가 있는 모험가는 치료할 수 없습니다.
- 비용: D 150 / C 300 / B 600 / A 1000 / S 1800 G (`GameManager.clinicCureCost`).
- `Tools > 치유소 세팅`과 `Tools > 길드 밖 화면 세팅`을 실행한 뒤 LobbyScene을 저장했습니다.

### 2.7 치명타·회피 (사용자 지시)
- 모험가 기본 치명타 10%, 회피 10%, 도적만 30% / 30%. 레벨업으로 오르지 않습니다 (`GameManager.combatStats`).
- 치명타는 기본 공격에만 붙습니다(스킬 제외, 화살 포함). 피해 숫자는 치명타 색입니다.
- 상세 창·접수처 정보에 "치명 10% | 회피 10%"를 표시합니다.
- `Ally_Rogue`의 자체 치명타 확률 필드는 지우고 공통 값을 씁니다.

### 2.8 관계·무드·말풍선 (사용자 결정: 무드는 사기와 분리, 부정 관계 포함)

| 관계 | 생기는 조건 (함께 던전을 마칠 때) | 효과 |
|---|---|---|
| 친우 | 완수, 케미 Lv.2 이상, 10% | 같은 파티면 매주 무드 +. 쓰러지면 쓰러뜨린 적에게 분노 |
| 연인 | 완수, 케미 Lv.3 이상, 한 명이 중상 이하로 돌아옴, 25% (둘 다 연인 없을 때) | 연인을 노리는 적 우선. 같은 파티면 무드 +, 떨어져 있으면 매주 −. 잃으면 우울함 확정 |
| 의형제 | 완수, 케미 Lv.2 이상, 위기(사망자 또는 중상 이하), 15%. 한 사람당 최대 2명 | 도주 시 낙오 확률 절반, 무드를 닮아감. 잃으면 50%로 쓰러뜨린 적 계열의 사냥꾼 특성 |
| 라이벌 | 나르시시스트가 끼면 10% (둘 다 20%) | 같은 파티면 공격력 +10%, 매주 무드 조금 − |
| 불화 | 도주·실패한 던전, 5% (다혈질이 끼면 10%) | 같은 파티면 케미가 쌓이지 않고 매주 무드 − |

- 한 쌍에 하나만 생기고, 연인 > 의형제 > 친우 순으로 더 깊은 관계로 바뀔 수 있습니다.
- 확률 배율: 외향적인 ×1.3, 내향적인 ×0.7, 겸손한(친우만) ×1.3, 둘 다 무드가 좋으면 ×1.5.
- 무드:
  - 사건별: 완수 +0.1, 실패 −0.15, 중상 −0.1, 레벨업 +0.1, 파티원 사망 −0.15 (친우 등 −0.4, 연인 −0.7), 좋은 관계 +0.3, 불화 −0.2
  - 매주: 0 쪽으로 0.05씩 돌아감
  - 효과: −0.5 이하면 공격하려 할 때 10%로 1.5초 멈춤
- 말풍선:
  - 모양: 흰 사각형과 꼬리, 초록 `:)` / 빨강 `:(`
  - 로비: 무드가 0.05 이상 바뀐 모험가의 치비 옆에 3초
  - 던전: 관계가 있는 동료가 쓰러지면 그 자리에서 `:(`
- 관계와 무드 모두 저장 파일에 들어갑니다.
- 관계 생성은 자동 + 알림으로 했습니다. 생성은 `GameManager.TryFormRelation` 한 곳에 모아 두어서 나중에 선택지를 붙일 수 있습니다.

## 4. 발견된 문제점과 해결 조언

### 4.1 관계가 늦게 생김
- **현상**: 파티를 고정해 6주를 돌렸는데 관계가 0건입니다.
- **원인**: 친우 조건인 케미 Lv.2에 같은 파티로 5번 완수가 필요합니다. 첫 친우는 빨라야 7~8주차입니다.
- **결정**: 사용자가 지금 값을 유지하기로 했습니다. 플레이해 보고 너무 늦으면 친우 조건을 Lv.1로 내리는 것을 추천합니다.

### 4.2 외눈박이가 회피를 0으로 만듦
- 기본 회피가 10%라서 외눈박이(−30%p)를 가지면 누구나 0%가 됩니다. 도적도 30%에서 0%가 됩니다.
- 도적에게는 치명적이지만 다른 직업에게는 −10%p와 같습니다. 직업 간 차이가 크면 곱연산(×0.7)으로 바꾸는 방법이 있습니다.

### 4.3 몬스터 수치에서 눈에 띈 점 (질문 답변 중)
- 랭크 배율이 A → S에서 크게 뜁니다 (HP 1.7 → 2.5, 공격력 1.5 → 2.0).
- 드래곤 HP(600)가 오크 백부장(900)보다 낮습니다. S랭크 보스방에서도 2250입니다.
- 슬라임·고블린·오크·스켈레톤은 스크립트에 수치가 고정돼 있어 프리팹에서 고칠 수 없습니다.

### 4.4 예전 저장 파일
- 지운 특성(전투 본능 등)은 불러올 때 빠집니다.
- 예전 '공명심' 성격은 '덜렁거리는'으로 바뀝니다.

## 5. 보완점

### 5.1 제가 임의로 정해서 확인이 필요한 것
- 치유소 비용 D 150 ~ S 1800 G, 시설 레벨 할인 없음
- 치명타 배율 ×1.5 (도적 ×2 유지), 적은 치명타·회피 없음
- 운 좋은의 '희귀 드랍' 기준(기본 확률 10% 이하), 단단한 피부 출혈 저항 = 받는 출혈 피해 −5%
- 신중한 간파 50%·기절 2초, 나르시시스트 막타 기준(공격 2번)·사기 ×1.5, 겸손한 −10% 두 가지
- 관계 발생 확률과 조건, 무드 변화량 전부 (2.8 표)
- 신전을 트라우마 전용으로 바꾼 것

### 5.2 측정의 한계
- 봇 판이 2~6주 × 1~2회뿐이고 D랭크라 크게 다친 사람이 거의 없었습니다.
- 트라우마·결함 획득, 겁쟁이 숨기, 분노, 의형제 복수 특성은 코드 경로가 실제로 돌지 않았습니다.

### 5.3 아직 재지 않은 것
- 치명타·회피 추가 후의 난이도 변화 (아군이 강해짐 → 기존 측정값과 비교 필요)
- 10주 이상 고정 파티에서 관계가 실제로 생기는 빈도
- 남아 있는 "[재측정]" 6개 설정 (오크 부락·재료 수급)

- 툴팁: 위치, 크기, 줄바꿈, 다른 창에 가려졌을 때 안 뜨는지
- 상세 창 성격·특성·트라우마·결함·관계 줄이 넘치지 않는지, 직업란 "겁쟁이 궁수", "무드: 좋음", "치명 10% | 회피 10%"
- 접수처 정보 칸에 한 줄 늘어난 치명·회피 표시
- 치유소 건물(4채 배치)과 치료 창
- 말풍선: 로비 치비 옆 크기·위치, 던전에서 유닛 앞에 그려지는지
- MISS / Zzz / ! 글자, 육감으로 보이는 지도 방 종류
- 앞 일지에서 남은 것: 킹 슬라임 점프, IMMUNE 글자, 22칸 맵, 방어력 표시 등

`Tools > 던전 빠른 테스트`로 던전에 바로 들어갈 수 있습니다.

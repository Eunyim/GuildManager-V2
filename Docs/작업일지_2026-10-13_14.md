# 길드 매니저 작업 일지 (2026-10-13 ~ 10-14)

한 세션에서 이어서 진행한 작업을 정리한 문서입니다. 수치는 모두 자동 플레이 봇(`Tools > TEMP 4주 플레이`)으로 잰 값이고, 화면에 어떻게 보이는지는 확인하지 못했습니다(6장 참고).

## 1. 현재 상태 요약

| 항목 | 상태 |
|---|---|
| 몬스터 공격력 | 원래의 2배 (HP, 공격 속도, 랭크 배율표는 그대로) |
| 전사 스킬 | "강한 베기" 삭제 → 받는 피해 20% 감소(패시브) + 방패 막기(다음 공격 3회 무효) |
| 던전 구조 | 방 3개 고정 → 방들이 동서남북으로 무작위로 이어지는 개미굴 구조 |
| 방 종류 | 전투 / 휴식 / 보물 / 보스 / 웨이브 |
| 적 종류 | 다크메이지 삭제. A랭크는 오크만, S랭크는 드래곤만 남음 |
| 파견 | 의뢰에 비해 약한 파티에 위험 경고 |
| 낙오자 | 월급 제외, 기한 만료로 죽으면 화면 알림 |

## 2. 한 일

### 2.1 실행해 보지 않았던 경로 검증

플레이 모드에서 실제로 돌렸고 검사가 모두 통과했습니다(실패 0건).

- 구출 기한 4주 만료: 기한이 3 → 2 → 1 → 0주로 줄고, 0주가 되면 명단·파티·구출 의뢰에서 빠짐
- 구출 전투 패배(전멸): 낙오자와 구출 의뢰가 그대로 남아 재도전 가능, 전멸한 파티원은 전사자 목록으로
- 신전 부활 버튼: 실제 클릭으로 부활(레벨 1, 요양 2주, 200G, 영혼석 소모)
- 파산 → 타이틀 → 새 게임: 이전 길드 데이터가 남지 않음, 저장 파일 삭제

### 2.2 낙오자 처리

- 낙오 중인 모험가는 월급 합계에서 제외 (`GameManager.GetTotalSalary`)
- 구출 기한이 끝나 죽으면 그 주의 알림에 빨간 글씨로 표시 (`LobbyManager.AdvanceWeek`)

### 2.3 파견 경고

- 파티 목록에서 약한 파티 옆에 빨간 "위험 (…)" 표시
- 위험한 파티는 첫 클릭에 경고만 뜨고, 같은 파티를 한 번 더 눌러야 출발 (막지는 않음)
- 기준 (`Scripts/Core/DispatchRiskRules.cs`, GameManager의 `dispatchRisk`)
  - 파티 평균 랭크가 의뢰 랭크 이상이면 안전
  - 한 랭크 낮으면 평균 레벨이 권장 레벨 이상일 때만 안전
  - 두 랭크 이상 낮으면 항상 위험

### 2.4 몬스터 공격력 2배

| 적 | 원래 | 지금 |
|---|---|---|
| 슬라임 | 10 | 20 |
| 고블린 | 8 | 16 |
| 스켈레톤 | 12 | 24 |
| 도적 | 15 | 30 |
| 오크 | 25 | 50 |

원래 수치 전체(HP, 사거리, 공격 간격, 랭크 배율표 포함)는 Claude 메모 `project_enemy_stats_rollback.md`에 있습니다. "몬스터 스탯 롤백"이라고 요청하면 되돌립니다.

### 2.5 전사 스킬 교체

- 패시브: 받는 피해 20% 감소 (`Ally_Warrior.damageReduction`)
- 액티브 "방패 막기": MP가 차면(평타 5번) 다음 공격 3회 무효 (`blockCount`). 막을 때 "BLOCK" 표시
- 두 수치는 전사 프리팹 인스펙터에서 조정 가능

### 2.6 개미굴 구조 던전

- 의뢰가 만들어질 때 방들이 격자 위에 무작위로 이어짐. 갈림길과 막다른 곁방이 생김
- 입구에서 가장 먼 방이 보스방이고, 정리하면 의뢰 완수
- 방을 정리하면 모닥불 화면에서 갈 방향(북/동/남/서)을 고름
- 지나온 방으로 되돌아갈 수 있고, 정리한 방은 전투 없이 지나감
- 지도에는 가 본 방과 거기에 붙은 방만 표시됨
- 방 개수(입구·보스 포함): D 4~5, C 5~6, B 6~7, A 7~8, S 8~10
- 수치: 로비 씬 QuestGenerator의 "던전 구조" (`DungeonLayoutSettings`)

### 2.7 방 종류 5가지

| 종류 | 동작 |
|---|---|
| 전투 | 적을 정리하고 상자를 열면 모닥불에서 30% 회복. 입구는 항상 전투방 |
| 휴식 | 전투 없이 체력 100% 회복 |
| 보물 | 전투 없이 상자. 골드 획득, 15% 확률로 미믹 |
| 보스 | 적이 한 마리 더 나옴. 정리하면 클리어 |
| 웨이브 | 적이 두 차례 몰려옴. 다 막으면 골드 획득 |

- 종류 비중(입구·보스 제외): 전투 50 / 휴식 15 / 보물 15 / 웨이브 20, 종류별 던전당 최대 2개
- 보물 골드: D 40~80, C 70~130, B 120~220, A 200~350, S 350~600
- 웨이브 골드: D 60~100, C 100~180, B 180~320, A 300~500, S 500~800
- 방에서 얻은 골드는 전멸하면 잃음
- 수치: 던전 씬 BattleManager의 "방 종류별 수치" (`DungeonRoomSettings`)

### 2.8 다크메이지 삭제

- 적 풀(A·S랭크)에서 빼고 스크립트와 프리팹을 삭제
- git 저장소가 아니라서 지운 파일을 `_Removed/DarkMage/`에 백업 (README에 복구 방법)

## 4. 발견된 문제점과 해결 조언

### 4.1 전사가 격주로 빠지고, 빠진 주에 파티가 무너진다 (가장 큼)

- **현상**: 실패의 대부분이 전사 없는 파티에서 나옴. 개미굴 구조 4주 측정에서 전사가 있으면 52전 50승, 없으면 28전 18승
- **원인**: 어그로가 전사 50, 나머지 5~10이라 모든 적이 전사를 침. 전사는 던전을 체력 70% 이하로 끝내 2주 요양에 들어가고, 다음 주에는 HP가 낮은 도적·마법사·사제가 직접 맞음
- **현재 방향**: 전사를 여러 명 두고 교대 (임시 결정)
- **조언**
  - 이 방향이 통하는지 먼저 재야 합니다. 봇이 전사를 우선 고용하고 교대시키게 고쳐 4주 측정
  - 두 번째 전사는 운에 달려 있습니다(방문자 4명 중 전사가 올 확률 주당 약 59%). 접수처에서 직업을 고를 수단이나 전사 방문 보정을 검토할 만합니다
  - 그래도 부족하면 부상 기준(70%)이나 경상 요양 기간(2주)을 완화

### 4.2 피해가 한 명에게 몰린다

- **현상**: 파티 평균 체력은 90%인데 전사만 죽음. 파티 HP의 약 59%는 전투 중 쓰이지 않음
- **조언**: 지금은 전사 방어로 버티게 했습니다. 장기적으로는 어그로를 일부 분산시키는 적(후열을 노리는 적)이나 도발 스킬처럼 "누가 맞는가"를 플레이어가 조절할 수단이 있어야 조합의 의미가 생깁니다

### 4.3 B랭크 의뢰가 보이는 시점과 깰 수 있는 시점의 간격

- **현상**: 명성 100은 C의뢰로 4주면 넘고 그때부터 보드의 30%가 B랭크. 그런데 Lv.4까지 C의뢰로 10주, B랭크 모험가 4명을 모으는 데 7주쯤 걸림 (계산값, 플레이로 확인 안 함)
- **조치**: 파견 경고를 넣음
- **조언**: 경고만으로 부족하면 경험치량을 올리거나 B랭크 등장 명성 기준을 높입니다

### 4.4 D랭크만 돌면 성장이 거의 없다

- **현상**: D의뢰 경험치가 30이라 4주 동안 Lv.2가 되는 인원이 평균 1명 안팎. C의뢰(60)는 3~4명
- **조언**: D의뢰 경험치를 올리거나, 첫 레벨업에 필요한 경험치(100)를 낮춥니다

### 4.5 전리품 수입이 의뢰 보상을 넘는다

- **현상**: 개미굴 구조에서 D랭크는 4주 동안 의뢰 보상 522G, 전리품 판매 572G. 곁방을 다 도는 것이 항상 이득
- **조언**: 방 종류의 골드 보상까지 더해졌으니 4주 경제를 다시 잰 뒤, 판매가(슬라임 점액 10G, 녹슨 검 12G)나 방당 드랍량을 조정합니다

### 4.6 A·S랭크의 적이 한 종류씩뿐이다

- **현상**: 다크메이지 삭제 후 A랭크는 오크만, S랭크는 드래곤만 나옴. 드래곤은 슬라임 스크립트를 쓰는 임시 적(분열만 꺼 둠)
- **조언**: A·S랭크용 적을 새로 정하거나, 그 전까지 B랭크 적을 A랭크 풀에 섞습니다

### 4.7 구출 기한이 끝난 낙오자는 흔적 없이 사라진다

- **현상**: 현역 명단에서만 지워지고 전사자 목록에 안 들어가 유해 수습과 부활이 불가능. 전투 중 전사자와 다르게 처리됨
- **조언**: 전사자 목록에 넣어 유해 수습이 가능하게 하는 쪽을 권합니다 (결정 대기)

### 4.8 기획서 파일이 없다

- **현상**: `길드 매니저.pdf`가 프로젝트 폴더에 없음. 기획서 4장의 "3방 구조"는 이번에 개미굴 구조로 바뀜
- **조언**: 파일 위치를 확인하고, 바뀐 내용(던전 구조, 방 종류, 전사 스킬)을 기획서에 반영합니다

### 4.9 버전 관리가 없다

- **현상**: 프로젝트가 git 저장소가 아니라서 되돌릴 수단이 수동 백업과 메모뿐
- **조언**: `git init`으로 저장소를 만들고 Unity용 `.gitignore`를 넣는 것을 권합니다. 이번처럼 수치와 구조를 크게 바꿀 때 롤백이 쉬워집니다

## 5. 보완점

### 5.1 제가 임의로 정해서 확인이 필요한 것

- 파견 경고 기준 (2.3)
- 전사 방어 수치 20% / 3회
- 방 개수 범위, 갈림길 확률 0.35, 보스까지 최단 경로가 전체의 절반 이상
- 방 종류 비중과 종류별 최대 2개, 웨이브 2회
- 휴식 회복 100%, 보물·웨이브 골드 범위
- 가 본 방에 붙은 방은 종류가 보임 (보스방 포함)
- 곁방에 특별한 보상 없음 (종류에 따른 보상만)
- 어느 방향에서 들어오든 아군은 왼쪽, 적은 오른쪽에 배치

### 5.2 측정의 한계

- 설정당 10전이 대부분이라 "10승"과 "8승"의 차이는 우연일 수 있습니다
- 봇은 건강한 모험가를 우선 편성하고, 동료가 쓰러지면 귀환하고, 절반이 쓰러지면 도주합니다. 실제 플레이어의 판단과 다르므로 실패 횟수는 참고치입니다
- 봇은 갈림길에서 안 가 본 방을 무작위로 고릅니다. 방 종류를 보고 고르지 않습니다
- 공격력 2배는 배율로 시험한 값이고, 스크립트에 반영한 뒤 같은 표를 다시 재지는 않았습니다(전사 방어를 넣은 뒤 측정으로 대체)

### 5.3 아직 재지 않은 것

- 방 종류가 들어간 뒤의 4주 경제와 난이도
- A·S랭크 (다크메이지 삭제 후 포함)
- 전사 2명 운용
- 실제 도주로 낙오가 생기는 경우, 유해 수습 승리 → 영혼석 → 부활로 이어지는 흐름
- 보물방 상자의 미믹 (이번 10회에서는 나오지 않음. 전투방·보스방 상자의 미믹은 확인)

### 5.4 구조적으로 남은 것

- 적 기본 스탯이 각 `Enemy*.cs`에 고정돼 있어 프리팹에서 조정할 수 없음 (하드코딩 금지 규칙 위반 상태)
- 모든 적이 슬라임 드랍 테이블을 그대로 씀
- 지도와 방향 버튼은 실행 중에 만들어짐. 디자인을 손보려면 씬에 미리 만들어 두는 방식으로 옮기는 편이 낫습니다
- 방에 들어온 방향이 전투 배치에 반영되지 않음
- 그래픽 대부분 임시

## 6. 직접 눈으로 확인하실 것

화면은 제가 볼 수 없어 전부 미확인입니다.

- 모닥불 화면: 지도가 창 안에 들어오는지, 방 칸의 종류 글자가 읽히는지, 종류별 색이 구분되는지
- 방향 버튼: 한 줄로 나오고 둘째 줄 글자가 넘치지 않는지
- 전사의 "BLOCK" 글자
- 파견 경고: 파티 목록 칸과 알림창에서 글자가 넘치지 않는지
- 낙오자 사망 알림(세 줄일 때)
- 이전부터 남은 것: 신전 창, 상점 창, 길드 밖 건물 3채, 데미지 숫자, 마우스 오버 말풍선

`Tools > 던전 빠른 테스트`로 던전에 바로 들어갈 수 있습니다.
